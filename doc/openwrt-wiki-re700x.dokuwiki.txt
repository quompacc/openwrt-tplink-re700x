====== TP-Link RE700X ======

The TP-Link RE700X is a dual-band Wi-Fi 6 (AX3000) wall-plug range extender
based on the Qualcomm IPQ5018 SoC with a QCN6122 companion radio for 5 GHz.

<WRAP center round important>
Support is provided out of tree / via PR — see the "Installation" section.
Flashing replaces the stock firmware. The stock bootloader has **no
button/TFTP recovery**, so have a UART console ready as a fallback.
</WRAP>

===== Installation =====

Two routes — no soldering is required for the web-GUI route.

==== Method A: stock web GUI (factory image) ====

  - Obtain ''openwrt-qualcommax-ipq50xx-tplink_re700x-squashfs-factory-webflash.bin''
    (release asset, or build it — see below).
  - On the stock RE700X: web UI → **System Tools → Firmware Upgrade**.
  - Upload the ''*-factory-webflash.bin'' and confirm.
  - The stock flasher writes OpenWrt into the inactive dual-boot slot; your
    stock firmware remains in the other slot as a fallback.

The image is wrapped into the stock "nvrammanager" upload container by
''scripts/tplink-re700x-factory.py'' (the same TP-Link safeloader/"tplink2022"
family as ''scripts/tplink-mkimage-2022.py'').

==== Method B: UART / TFTP (recovery or development) ====

  - **Back up the stock NAND first** and keep it.
  - RAM-boot the initramfs via U-Boot/TFTP before touching flash: <code>
setenv serverip <host>; setenv ipaddr <dev>
tftpboot 0x44000000 ...-initramfs-uImage.itb
bootm 0x44000000</code>
  - From the booted OpenWrt: ''sysupgrade -n ...-squashfs-sysupgrade.bin''

==== Build the factory image yourself ====

Standard OpenWrt build for target ''qualcommax'' / subtarget ''ipq50xx'',
device profile ''tplink_re700x''. The build emits ''sysupgrade.bin'' and
''factory-webflash.bin''.

===== Serial / UART =====

3.3 V TTL, **115200 8N1**. The unpopulated 4-pad header sits next to the
RF-shield edge. Pads top-to-bottom are **TX, RX, GND, VCC** (silkscreen
labelled). Use a 3.3 V adapter and leave **VCC disconnected**.

{{:media:tp-link:re700x-uart-header.jpg?400|RE700X UART header — TX/RX/GND/VCC top-to-bottom}}

To break into U-Boot, hold the break string ''tpl'' on the console during
power-up. Dual-boot slot is selected by the ''tp_boot_idx'' U-Boot env var;
recover a mis-set slot with: <code>
setenv tp_boot_idx 0; saveenv</code>

===== Note on the dual-boot brick fix =====

The stock U-Boot passes a slot-correct ''ubi.mtd='' (''rootfs'' / ''rootfs_1''
per ''tp_boot_idx'') but with an unmountable ''root=mtd:ubi_rootfs''. The DTS
''/chosen'' inherits the slot-correct ''ubi.mtd='' and appends
''root=/dev/ubiblock0_1'', so OpenWrt boots from whichever slot the flasher
wrote — no brick.
